# Kuwi brand reference

Kuwi (pronounced “koo-WEE”) is Quilla’s gender-neutral, maya-inspired study bird. They are calm, attentive, patient, resourceful, and quietly optimistic. Kuwi supports the learning journey without representing an examiner, an authority figure, or a guarantee of passing the Civil Service Examination.

## Recognition system

- The clockwise marigold tail forms a capital **Q** through its outer contour and negative space.
- One softly swept crown feather echoes a writing quill.
- The full character uses a compact blue body, cream face and belly, small marigold beak, and deep-ink outlines.
- Large illustrations may show a hard lower-right shadow. Marks below 64 px remove the shadow, feet, feather details, and interior outlines.
- The header and application icon place the deep-ink micro mark inside Quilla’s existing marigold rounded-square badge.

## Expression guidance

The reference sheet covers guide, think, focus, practice, review, celebrate, retry, and rest poses. Mistake-related states should look reassuring rather than disappointed. Celebration should reward effort and mastery rather than imply guaranteed exam success.

## Guardrails

- Do not add government uniforms, flags, seals, laurels, shields, maps, or Civil Service Commission marks.
- Do not show real or leaked examination papers, fabricated scores, medals, or pass guarantees.
- Do not add glasses, graduation caps, speech bubbles, gender-coded styling, or childlike proportions.
- Keep the bird visually distinct from owl mascots and other well-known bird marks.
- Treat the hero illustration as decorative; the surrounding HTML must carry all essential meaning.

## Vector-generation workflow

The runtime SVG artwork is generated by Visioncortex VTracer
`1.0.0-alpha.4`; none of the mascot paths are hand-authored. The trace profile
uses eight-bit color precision, no curve simplification, three-decimal path
precision, and a balanced layer threshold. Pixel comparisons at each source's
native dimensions measured approximately 99% normalized mean-channel
similarity across the four outputs. This preserves the generated artwork's
shape, shading, outline, and transparent edges without embedding the PNG in an
SVG wrapper. The measured native-size results are:

| Asset             | Normalized similarity |
| ----------------- | --------------------: |
| Hero              |              98.9978% |
| Color mark        |              99.0023% |
| Monochrome mark   |              98.8720% |
| Horizontal lockup |              99.3262% |

These values compare every RGBA channel after rendering each SVG at the source
PNG's exact dimensions. A vector trace cannot be mathematically identical to
the antialiased raster input, so the measured values are used instead of a
claim of 100% equivalence.

To trace all vector assets from the committed source PNGs:

```powershell
python scripts/trace-kuwi-assets.py
```

The Python command requires `vtracer==1.0.0a4`. The exact trace settings and
source-to-output mapping live in `scripts/trace-kuwi-assets.py` so future
changes remain reproducible and reviewable.

The character reference sheet and raster sources are documentation assets;
they are not requested by the landing page at runtime.
